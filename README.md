Sistemas Operativos Móviles

Los sistemas operativos móviles son programas que permiten
administrar los recursos de un teléfono y ejecutar aplicaciones.

Principales sistemas operativos móviles:
- Android
- iOS
- HarmonyOS
- KaiOS

Funciones:
- Administrar aplicaciones.
- Gestionar la memoria.
- Controlar el hardware.
- Administrar archivos.
- Proporcionar seguridad.
